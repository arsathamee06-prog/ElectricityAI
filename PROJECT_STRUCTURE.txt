## Model Performance Metrics

Each model is evaluated on:
- **RMSE** (Root Mean Squared Error) - Overall accuracy
- **MAE** (Mean Absolute Error) - Average deviation
- **MAPE** (Mean Absolute Percentage Error) - Relative error
- **R² Score** - Explained variance
- **Directional Accuracy** - Correct trend predictions

## Next Steps After Setup

1. **Prepare Your Data**
   - Collect or download electricity demand CSV data
   - Ensure it has 'timestamp' and 'demand' columns
   - Minimum 100 data points recommended

2. **Train Models**
   ```bash
   python backend/train_models.py --data_path data/your_electricity.csv
   ```

3. **Start the System**
   ```bash
   python run_system.py
   ```

4. **Access Dashboard**
   - Browser automatically opens
   - Or navigate to http://localhost:5000/frontend

5. **Explore Features**
   - Generate forecasts
   - Compare models
   - View insights
   - Monitor API

6. **Customize (Optional)**
   - Adjust model parameters in config.py
   - Retrain models
   - Modify dashboard styling
   - Extend API endpoints
